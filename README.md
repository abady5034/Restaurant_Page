#  Restaurant Page

This project is a responsive **Restaurant Page** designed to showcase a modern and visually appealing restaurant website.  
The website focuses on clean layout, smooth navigation, and user-friendly design to provide visitors with an engaging browsing experience.

---

##  Features
- Modern and clean UI design
- Fully responsive layout for different screen sizes
- Organized sections for restaurant information
- Attractive visuals and styling
- Smooth navigation between sections

---

##  Technologies Used
- HTML5  
- CSS3  

---

##  Project Goals
- Practice front-end web development fundamentals
- Improve skills in layout design and responsiveness
- Build and deploy a real project using **GitHub Pages**
